# Agent Instructions

## Git Operations
- **NEVER** commit without explicit user command
- **NEVER** push without explicit user command
- Wait for user to say "commit" or "push" before doing either

## Browser / Dev Server
- **NEVER** open browser without explicit user command
- **NEVER** start dev server in background without explicit user command
- Only run `npm run dev` when user asks

## General
- Ask before taking any action that modifies repository state
- Ask before opening any external tools (browser, etc.)
